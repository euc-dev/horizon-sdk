# `v6.GetScreenCaptureProtection`

Returns the current status of Horizon's Screen Capture Protection feature. This feature prevents users from including the remote desktop when capturing or printing the screen.

The value can change while the session is in progress. To receive notification when it changes, set `VDPScreenCapture_Sink.v6.OnScreenCaptureProtectionChanged()` in the screen capture sink.

The feature state is set through a group policy on the remote desktop and is not known until the Horizon Client receives a message from the remote desktop. Until then, this function returns `VDP_SCREEN_CAPTURE_ERROR_HOST_NOT_READY`; the feature can be assumed to be disabled until the state is reported.

The Screen Capture Protection feature does not affect the Screen Capture API. The API can still capture the remote desktop when the feature is disabled.

This function is a member of `VDPScreenCapture_Interface`.

## Method Signature

```c
VDPScreenCapture_Error (*v6.GetScreenCaptureProtection)(
    VDPScreenCapture_ContextId contextId,
    Bool* pEnabled
);
```

## Parameters

| Parameter   | Description                                                                               |
| ----------- | ----------------------------------------------------------------------------------------- |
| `contextId` | The context ID returned from `v1.Init()`.                                                 |
| `pEnabled`  | Returns `TRUE` when Screen Capture Protection is enabled and `FALSE` when it is disabled. |

## Return Values

| Value                                        | Description                                                          |
| -------------------------------------------- | -------------------------------------------------------------------- |
| `VDP_SCREEN_CAPTURE_ERROR_SUCCESS`           | The feature state was returned.                                      |
| `VDP_SCREEN_CAPTURE_ERROR_HOST_NOT_READY`    | The feature state has not yet been received from the remote desktop. |
| `VDP_SCREEN_CAPTURE_ERROR_INVALID_PARAMETER` | An input parameter is invalid.                                       |
