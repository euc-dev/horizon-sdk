# `v5.GetHostWindowForDesktop`

Returns the host window ID that covers the entire remote desktop, including multi-monitor modes.

The host window ID can change while Horizon is running. The `VDPScreenCapture_Sink.v1.OnTopologyChanged()` callback is called with the `VDP_SCREEN_CAPTURE_HOST_WINDOWID_CHANGED` flag when the host window changes.

This function is a member of `VDPScreenCapture_Interface`.

## Method Signature

```c
VDPScreenCapture_Error (*v5.GetHostWindowForDesktop)(
    VDPScreenCapture_ContextId contextId,
    uintptr_t* pHostWindow
);
```

## Parameters

| Parameter     | Description                               |
| ------------- | ----------------------------------------- |
| `contextId`   | The context ID returned from `v1.Init()`. |
| `pHostWindow` | Returns the host window ID.               |

## Return Values

| Value                                        | Description                      |
| -------------------------------------------- | -------------------------------- |
| `VDP_SCREEN_CAPTURE_ERROR_SUCCESS`           | The host window ID was returned. |
| `VDP_SCREEN_CAPTURE_ERROR_INVALID_PARAMETER` | An input parameter is invalid.   |
