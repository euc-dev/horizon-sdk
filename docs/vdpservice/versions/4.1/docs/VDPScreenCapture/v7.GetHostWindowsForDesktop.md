# `v7.GetHostWindowsForDesktop`

Returns the platform-specific identifiers and attributes for the Horizon Client windows that display the remote desktop. A single window is returned in windowed and single-monitor modes; multiple windows may be returned in multi-monitor modes.

On input, `*pWindowCount` is the number of entries available in `pWindows`. On output, it is the number of windows required. Pass `pWindowCount` as `0` and `pWindows` as `NULL` to query the required count.

Each returned `VDPScreenCapture_HostWindowInfo.structSize` is set to `sizeof(VDPScreenCapture_HostWindowInfo)` by this function. The identifiers and attributes can change while Horizon is running. Re-query when `VDP_SCREEN_CAPTURE_HOST_WINDOWID_CHANGED` or `VDP_SCREEN_CAPTURE_PIXELSCALE_CHANGED` is reported through `VDPScreenCapture_Sink.v1.OnTopologyChanged()`.

This function is a member of `VDPScreenCapture_Interface`.

## Method Signature

```c
VDPScreenCapture_Error (*v7.GetHostWindowsForDesktop)(
    VDPScreenCapture_ContextId contextId,
    uint32* pWindowCount,
    VDPScreenCapture_HostWindowInfo* pWindows
);
```

## Parameters

| Parameter      | Description                                                                                      |
| -------------- | ------------------------------------------------------------------------------------------------ |
| `contextId`    | The context ID returned from `v1.Init()`.                                                        |
| `pWindowCount` | On input, the capacity of `pWindows`; on output, the number of windows required or returned.     |
| `pWindows`     | Receives the desktop window identifiers and attributes. Pass `NULL` to query the required count. |

## Return Values

| Value                                        | Description                          |
| -------------------------------------------- | ------------------------------------ |
| `VDP_SCREEN_CAPTURE_ERROR_SUCCESS`           | The window information was returned. |
| `VDP_SCREEN_CAPTURE_ERROR_INVALID_PARAMETER` | An input parameter is invalid.       |
