# `v6.OnScreenCaptureProtectionChanged`

This event handler is called when the Screen Capture API detects a change to Horizon's Screen Capture Protection feature. A callback is issued with the initial value, and again if the status changes while a session is in progress.

**Member of**: `VDPScreenCapture_Sink`  
**Method Signature**:

```c
void (*v6.OnScreenCaptureProtectionChanged)(
    void* userData,
    VDPScreenCapture_ContextId contextId,
    Bool enabled
);
```

### Parameters

| Parameter   | Description                                                          |
| ----------- | -------------------------------------------------------------------- |
| `userData`  | The `userData` parameter passed in to `v1.Init()`.                   |
| `contextId` | The context ID returned from `v1.Init()`.                            |
| `enabled`   | `TRUE` when Screen Capture Protection is enabled; otherwise `FALSE`. |

**Return Values**: None
